# Анализ налоговой задолженности России за 2016–2018 годы

Исследование открытых статистических данных ФНС России.

**Инструменты:** Microsoft Excel, HTML, визуализация данных.

## Результаты проекта

- Анализ динамики и структуры налоговой задолженности за 2016–2018 годы.
- Расчёт абсолютных и относительных изменений.
- Анализ задолженности по видам налогов и недоимки.
- Выявление особенностей статистической отчётности и ограничений сопоставимости.
- Разработка рекомендаций по повышению эффективности взыскания.
