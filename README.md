
# Проекты по анализу данных

В этом репозитории представлены мои учебные проекты по анализу данных с использованием Excel, Power BI, SQL и Python.

Проекты включают обработку и исследование данных, расчёт аналитических показателей, визуализацию результатов и формирование выводов.

## Проекты

### 1. Анализ налоговой задолженности России, тестовое задание от ФНС (2016–2018)

**Инструменты:** Excel, HTML

Анализ открытых статистических данных ФНС России. Исследование динамики и структуры задолженности, расчёт аналитических показателей, выявление тенденций и разработка рекомендаций.

- [Открыть аналитический отчёт](https://ilyakan17.github.io/analytics-projects/01-tax-debt-analysis/)
- [Файлы и описание проекта](./01-tax-debt-analysis/)

### 2. Анализ финансовых показателей в Power BI

**Инструменты:** Power BI, Power Query, DAX

Разработка аналитического отчёта по продажам, прибыли и рентабельности. Подготовка данных, создание модели, расчёт KPI и разработка интерактивных визуализаций.
